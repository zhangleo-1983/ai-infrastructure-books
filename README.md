# AI Infrastructure Books

《AI 基础设施从零开始》是一套面向普通 AI
用户、知识工作者、内容创作者和小企业主的中文技术入门图书。

项目希望帮助没有 Linux、服务器和编程基础的用户，逐步建立自己的 AI
基础设施能力。

本项目不是传统的开发者文档，也不是只提供命令的速查手册。

每一册都需要同时回答：

-   这是什么
-   为什么需要它
-   应该如何操作
-   成功后是什么样
-   失败时如何判断
-   什么时候不应该这样做

## 开发原则

1.  先完成第二册迁移，再开发其他册。
2.  不擅自改变书名、章节顺序和技术路线。
3.  不删除已经确认的正文。
4.  不使用真实软件截图作为主要教学资源。
5.  仿真界面使用 HTML、CSS 或内联 SVG。
6.  手机端为一级阅读场景。
7.  所有专业术语第一次出现时必须解释。
8.  技术事实优先依据官方资料。
9.  涉及版本变化需注明校订日期。
10. 大规模修改前先提交实施计划。

## 本地开发

环境要求：

- Node.js 22.12 或更高版本
- npm 9.6.5 或更高版本

首次安装：

``` bash
npm ci
```

常用命令：

``` bash
npm run dev
npm run build
npm run typecheck
npm run lint
npm run test
npm run check:content
npm run check:links
npm run check:release
npm run test:e2e
npm run check
npm run check:all
```

`npm run check:content` 和 `npm run check:links` 需要先完成 `npm run build`。
`npm run check` 会按照正确顺序运行类型检查、Lint、测试、构建、内容完整性和内部链接检查。

Pagefind 索引只在 production build 后生成。`npm run dev` 便于编辑正文，
但不会生成 `/pagefind/` 索引，因此开发服务器中的搜索会显示明确提示。
需要验证真实搜索时，请运行：

``` bash
npm run build
npm run preview
```

搜索索引只收录带 `data-pagefind-body` 的独立内容页正文，整册打印页、404、
站点导航和重复目录不会进入索引。主题与阅读状态只保存在浏览器本机；
第二册完成率的定义与数据格式见
`docs/interaction/book02-completion-rules.md`。

完整工程说明见：

- `docs/architecture.md`
- `docs/design-system.md`
- `docs/content-authoring.md`
- `docs/search.md`
- `docs/interactions.md`
- `docs/deployment.md`
- `docs/print-and-pdf.md`
- `docs/testing.md`
- `docs/content-review.md`
- `docs/adding-book03.md`

部署到 GitHub Pages 项目子路径时，可通过 `.env` 中的 `BASE_PATH` 配置路径前缀；
设置公开域名 `SITE_URL` 后才会生成 sitemap。参考 `.env.example`。
