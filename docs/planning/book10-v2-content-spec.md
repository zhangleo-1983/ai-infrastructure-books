# 新第十册内容规格：Harness

状态：主线规划与完整 draft 建立中；旧第十册服务器安全运维保留为选读路线。

书名暂定：《Harness：测试、评估与长期迭代》

## 读者完成后的结果

读者能够为一个 AI 任务准备代表性测试样例，区分事实、格式和风格评价，记录人工判断与成本，在提示、模型或工具变化后发现回归，并把结果交接给别人。

## 章节数量设计

Harness 的核心不是多跑几次 Prompt，而是建立可重复的判断系统。原 12 章缺少三处关键连接：基准好坏样例让评分标准落地，自动评审边界防止“AI 给 AI 打分”代替人工，上线后漂移监测让一次验收延伸到长期使用。因此正文调整为 15 章。
