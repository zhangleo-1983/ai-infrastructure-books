# 新第七册内容规格：Prompt 与上下文

状态：主线规划与完整 draft 开始建立；旧第七册 n8n 保留为选读 / 开源共建路线。

书名暂定：《Prompt 与上下文：让 AI 稳定完成任务》

## 读者完成后的结果

读者不需要学习代码。完成本册后，读者能够把一个模糊目标拆成清楚的任务说明，准备最小资料包，要求 AI 分阶段工作，并用验收标准检查结果。
