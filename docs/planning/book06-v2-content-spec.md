# 新第六册内容规格：AI 工作伙伴入门

状态：新主线规划与三章样章 draft；旧第六册保留为选读路线。

书名暂定：《AI 工作伙伴入门：Codex、Claude 与 WorkBuddy》

## 读者完成后的结果

读者不需要部署服务器或数据库。完成本册后，读者应能：

1. 说清楚聊天产品、AI 工作伙伴和自动化工具的区别；
2. 根据任务的隐私、复杂度和可复核性选择工具；
3. 把文件、背景、目标、限制和验收标准交给 AI；
4. 在开始前检查 AI 拥有哪些文件与工具权限；
5. 完成一次“小任务—检查—修改—交付”的协作闭环；
6. 发现回答不可靠时停止扩大范围，并保留可复核记录。

## 内容边界

- Codex、Claude、WorkBuddy 作为示例，不把某个品牌界面写成永久不变的事实。
- 先讲任务模式，再讲按钮位置；界面改变时，读者仍可迁移方法。
- 不要求读者购买 API、安装命令行、配置 VPS 或编写代码。
- 不承诺 AI 自动正确，也不把“有权限”解释为“可以无条件执行”。
- 敏感资料、付款、删除、对外发送和发布动作必须保留人工确认点。

## 三章样章写作基线

- 第一章先解决“我该用哪个工具”的焦虑；
- 第二章让读者在不写代码的情况下产出一份可复用任务简报；
- 第三章通过文件清单和权限检查，建立资料边界；
- 每章都包含：做什么、为什么、成功状态、失败判断、停止条件。
