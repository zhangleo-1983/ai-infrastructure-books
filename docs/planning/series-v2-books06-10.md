## 处理原则

- 现有第六至第十册保留原正文和 URL，改为“选读 / 开源共建”路线，不删除历史实机记录。

- 新主线第六至第十册使用新的内容定位和章节规划，不覆盖旧正文；完成新稿并验收后再决定主站 URL 的切换方式。

## 词汇与范围

“WorkBuddy”“小龙虾”等产品或社区称呼只有在确认具体工具和官方来源后才写入正文。主线优先写稳定的任务模式和边界，再用产品作为示例，避免因界面或品牌变化导致整册失效。

Dify、n8n、Supabase、服务器和 Docker 不从系列中消失，它们归入选读路线或进阶索引；新主线不要求读者先购买 VPS、配置域名或维护数据库。

## 迁移顺序

1. 为旧第六至第十册补齐选读标签、实机状态和共建说明。
2. 为新第六册完成读者结果、章节提案和三篇样章。
3. 依次完成新第七至第十册，不提前覆盖旧路线 URL。
4. 新主线完成内容、链接、响应式、打印和可读性检查后，再决定导航呈现与 URL 迁移。
