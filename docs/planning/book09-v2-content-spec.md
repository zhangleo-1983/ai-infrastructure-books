# 新第九册内容规格：Vibe coding

状态：主线规划与完整 draft 建立中；旧第九册开发环境保留为选读路线。

书名暂定：《Vibe coding：从想法到可用原型》

## 读者完成后的结果

读者能够把一个小想法写成需求，选择低风险原型范围，让 AI 协助生成和修改代码，使用浏览器、日志和测试检查结果，并知道何时停止扩大范围。

## 章节数量设计

原 12 章能够完成“想法到可点击原型”，但缺少新手最容易忽略的三个独立检查点：修改前建立版本与恢复点、验证手机端和无障碍、在试用前检查隐私与安全。三项都直接决定原型能否安全交给别人，因此正文调整为 15 章。
