# 样章二：把愿望写成任务简报

“帮我把这篇文章写好”是愿望，不是可执行任务。AI 需要知道对象、目的、材料、限制和验收方式。你不必使用术语，只要把这些信息写完整。

## 五个必要部分

1. **目标**：最终要解决什么问题？
2. **读者**：谁会使用结果？
3. **材料**：允许 AI 参考哪些文件或链接？
4. **限制**：不能改变什么，不能做什么？
5. **验收**：你准备怎样判断结果合格？

可以直接套用下面的模板：

```text
目标：请把【材料】整理成【结果】。
读者：结果给【谁】使用，他们已知【什么】，不知道【什么】。
材料：只使用【文件/段落】；不确定的内容请标记。
限制：保持【语气/长度/格式】；不要【禁止动作】。
验收：完成后请列出【检查项】，并说明仍然不确定的地方。
```

## 为什么要写验收标准

没有验收标准，AI 很容易用“看起来完整”代替“真正可用”。例如，一份给新手看的操作说明，合格不只是语句通顺，还要让读者知道做什么、为什么、成功状态和失败判断。

## 一次可复核的对话

先让 AI 复述任务，不要立即要求最终答案。你可以说：“先复述你的理解，列出缺少的信息，不要开始写。”如果复述错了，及时改正；如果它列出的材料超出你的授权范围，先停止。

成功状态是：任务简报被你确认，AI 明确列出不确定点。失败判断是：它直接开始编造背景、假设你同意了未提供的资料，或把建议说成已经完成。
