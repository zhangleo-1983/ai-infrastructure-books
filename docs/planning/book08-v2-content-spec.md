# 新第八册内容规格：Skill、插件与 MCP

状态：主线规划与完整 draft 建立中；旧第八册 Supabase 保留为选读路线，云端实机验证待完成。

书名暂定：《Skill、插件与 MCP：扩展 AI 的能力边界》

## 读者完成后的结果

读者能够判断一个扩展能力是否值得安装，读懂它需要哪些数据和权限，在启用前后保留证据，并在不用时撤销连接、凭证和访问范围。

## 章节数量设计

本册不沿用固定 12 章。Skill、插件和 MCP 分别需要“理解、试用、权限与退出”环节，压缩到 12 章会只剩概念介绍，读者无法完成一次安全练习。因此正文调整为 17 章：前 3 章建立共同评估方法，第 4—5 章学习 Skill，第 6—9 章学习插件和 MCP，第 10—13 章控制权限与执行，第 14—17 章处理组合、更新、交接和长期目录。
