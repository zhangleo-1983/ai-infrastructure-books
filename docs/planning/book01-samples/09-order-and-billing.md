# 样章：下单前最后核对费用

> 第一册《15分钟搞定你的VPS》第 9 章样稿
>
> 样稿日期：2026-07-27
>
> 状态：用于确认时效性信息的表达方式，不是正式 MDX

你已经选择了地区、套餐、Ubuntu 和登录方式。

先不要点击 Deploy。

这一章只做一件事：把“我以为要付多少钱”变成“我知道哪些项目会计费，以及怎样停止
继续计费”。

VPS 是持续占用资源的服务。购买时最危险的误解，不是多花一两元，而是以为关机就会
停止账单，或者把账户充值金额当成服务器价格。

## 先区分四种金额

购买流程里可能同时出现四类金额。

### 1. 套餐价格

这是服务器本身的计算、内存、磁盘和网络资源费用。

Vultr 页面可能同时显示小时价格和月度参考价格。对本书而言，你需要记录两个值，但
最终应以结算摘要和 Billing History 为准。

### 2. 账户充值或余额

支付页面要求存入账户的金额，不一定等于一台服务器一个月的价格。

它更像向账户钱包充值。服务器创建后，费用再从账户余额或付款方式中结算。

不要看到“支付了 US$10”就推断服务器月费一定是 US$10。

### 3. 附加服务

常见附加项目包括：

- 自动备份；
- 快照存储；
- 额外公网 IPv4；
- DDoS 防护；
- 块存储；
- 负载均衡；
- 额外支持服务。

第一册主线只需要一台普通 Cloud Compute 实例、一个独立公网 IPv4 和用于 SSH 的最小
防火墙规则。

### 4. 税费、汇率和支付机构费用

Vultr 当前以美元出具账单。中国用户使用支付宝、银行卡或 PayPal 时，实际人民币金额
还可能受到支付机构汇率或费用影响。

这些金额不能用教程中的一次截图永久表示。正式正文只能展示带校订日期的例子，并要求
读者在自己的结算页确认。

## 用教学结算卡逐项核对

下面是仿真结构，不是当前价格截图：

| 项目 | 教学状态 | 你需要检查什么 |
| --- | --- | --- |
| Cloud Compute | 已选择 | 当前小时价和月度参考价 |
| Location | Tokyo | 该地区是否改变套餐价格 |
| Ubuntu 24.04 LTS | 已选择 | 是否存在系统授权费；Ubuntu 通常不应出现 Windows 授权费 |
| Primary IPv4 | 必需 | 是否已包含，是否显示额外费用 |
| Automatic Backups | Off | 第一册主线不购买 |
| Additional Storage | None | 没有额外块存储 |
| DDoS Protection | Off | 没有误选额外服务 |
| Estimated Total | 以控制台为准 | 币种、计费周期和附加项是否一致 |

### 做什么

从上往下读一遍，不要只看最后一个总价。

### 为什么这样做

总价相同，也可能来自不同组合。一个页面可能是服务器价格，另一个页面可能已经加入
备份或额外存储。

### 成功后是什么样

- 只有你需要的 Cloud Compute 实例；
- 自动备份、额外存储和额外服务没有被默认勾选；
- 公网 IPv4 的状态和费用明确；
- 你能说出金额的币种和计费周期。

### 失败时如何判断

- 总价比套餐卡高，但不知道高在哪里；
- 页面显示多个实例或多个地区；
- 出现 Windows License、Block Storage 或 Load Balancer；
- 自动备份已经打开，但你不知道它会增加多少费用；
- 结算页没有显示币种。

遇到这些情况，不要付款。返回上一页逐项检查。

## 关机不等于停止计费

这是本章最重要的规则。

截至本样章校订日期，Vultr 官方说明：实例即使处于停止状态，只要还没有销毁，CPU、
内存、磁盘和 IP 等资源仍被保留，因此仍会正常计费。

```text
Restart / Reboot  重新启动，不停止计费
Stop              暂停运行，仍然计费
Destroy           释放实例，服务器数据永久删除，实例费用停止
```

“Destroy”是破坏性操作。它不是暂停按钮。

### 为什么停止后还收费

因为服务商仍为这台实例保留：

- CPU 和内存配额；
- 系统磁盘；
- IP 地址；
- 实例配置。

这些资源没有提供给其他用户，所以账单继续。

### 销毁前要检查什么

销毁实例前必须先确认：

1. 这确实是要删除的实例；
2. 需要的数据已经备份；
3. 交接卡记录不再被后续章节使用；
4. 账户里没有需要保留的快照、额外磁盘或保留地址；
5. 你理解销毁后不能再用原密码或私钥登录这台实例。

本章只解释计费关系，不要求你现在销毁服务器。

## 自动备份为什么默认关闭

截至 2026-07-27，Vultr 官方说明自动备份会在实例基础小时/月度费用之外增加 20%。
这个比例是易变事实，正式发布前必须复核。

自动备份本身有价值，但第一册主线刚创建的是练习服务器：

- 还没有重要业务数据；
- 还没有安装第二册的配置；
- 目标是先确认购买和登录路径；
- 打开备份会让第一张账单更难理解。

因此第一册默认关闭自动备份。

这不代表“备份没用”。进入第二册、节点配置稳定后，应根据数据价值重新决定是否开启
自动备份或制作快照。

成功判断：

- 创建摘要显示 Automatic Backups 为 Off；
- 你知道关闭备份意味着服务商不会替你自动保存可恢复副本；
- 你已经计划在配置产生价值后重新评估。

失败判断：

- 备份被默认选中但你没有看到；
- 你因为关闭备份而误以为服务器数据不会丢失；
- 你准备存放重要资料，却仍没有任何备份方案。

## 快照也可能继续产生费用

快照是某个时间点的磁盘副本。它可以在销毁实例后继续存在。

这意味着：

```text
销毁服务器 ≠ 自动清除账户里的全部收费资源
```

截至本样章校订日期，Vultr 官方按快照压缩后的存储量计费。具体单价可能变化，因此
正文应引导读者在 Billing 页面查看，而不是只记住一个数字。

以后不再使用服务器时，需要分别检查：

- Compute Instances；
- Snapshots；
- Block Storage；
- Reserved IP；
- Load Balancers；
- 其他仍在运行的产品。

成功状态是账户中没有你无法解释的活动资源，而不是“实例列表空了就一定没费用”。

## 流量额度用完后会怎样

套餐包含的 Transfer 不是无限流量。

截至本样章校订日期，Vultr 官方说明：

- 带宽用量可以在 Bandwidth Usage 页面查看；
- 超出套餐额度可能产生额外费用；
- 当前官方超额价格需要在发布时重新核对。

第一册不要求你预测第二册会用掉多少流量，但必须建立两个习惯：

1. 知道套餐包含多少流量；
2. 定期查看实际用量和是否出现 overage。

不要把“1 TB”理解成：

- 每秒 1 TB；
- 永远不会用完；
- 所有方向在所有服务商处都用相同方法计费；
- 删除实例后旧的超额费用会消失。

## 支付成功不等于可以忽略账单

中国用户可能选择支付宝，也可能使用服务商当前支持的银行卡或 PayPal。

无论用哪一种方式，都要保存：

- 支付成功记录；
- 账户 Billing History；
- 实例创建时间；
- 当前活动服务列表；
- 服务商的官方发票或账单。

不要在教程截图、聊天或普通文档中保存：

- 完整银行卡号；
- 支付密码；
- 身份证件；
- PayPal 登录信息；
- 账户恢复代码。

如果支付宝或银行卡显示扣款，但 Vultr 余额或订单状态没有更新，不要立刻重复支付。
先检查：

1. 支付状态是成功、处理中还是失败；
2. Vultr Billing History 是否有记录；
3. 邮件是否要求额外验证；
4. 是否只是临时预授权；
5. 是否需要联系支付机构或 Vultr 官方支持。

重复付款可能让问题变得更复杂。

## 下单前的 60 秒检查

按顺序回答下面的问题：

### 服务器

- [ ] 只有一台 Cloud Compute / Shared CPU 实例；
- [ ] 地区是东京，或你已经记录为什么使用洛杉矶；
- [ ] 配置不低于 1 vCPU、1 GB RAM、25 GB 系统盘和 1 TB 流量；
- [ ] 系统是 Ubuntu 24.04 LTS x64；
- [ ] 套餐包含独立公网 IPv4。

### 附加项

- [ ] Automatic Backups 为 Off；
- [ ] 没有额外块存储；
- [ ] 没有额外公网 IP；
- [ ] 没有误选 DDoS、负载均衡或其他服务；
- [ ] 云防火墙只准备开放 TCP 22。

### 费用

- [ ] 我知道当前页面使用美元；
- [ ] 我已经看到小时价格和月度参考价格；
- [ ] 我知道充值金额不一定等于月费；
- [ ] 我知道停止实例仍会计费；
- [ ] 我知道只有销毁实例才能停止该实例继续占用资源；
- [ ] 我知道快照等独立资源可能继续收费；
- [ ] 我能在 Billing History 找到后续明细。

任何一项不能确认，都先不要点击 Deploy。

## 本章结束时

你不需要背下所有价格。

你需要真正记住的是：

```text
创建开始计费
停止仍然计费
销毁会删除实例数据
附加资源需要单独检查
```

看到结算摘要符合需求卡，并且你能解释每一项费用后，才进入下一章确认服务器开通状态。
