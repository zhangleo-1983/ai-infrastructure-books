# 第二册完成率规则

校订日期：2026-07-26

第二册的本地完成率采用以下固定规则：

- 第 1—12 章计入完成率，总数为 12。
- “开始之前”不计入完成率。
- 附录不计入完成率。
- 资料来源不计入完成率。
- 12 个编号章节全部完成时，目录显示“本册完成”。

完成状态使用书号和章节 `slug` 作为稳定标识，不读取完整 URL，因此部署到 GitHub
Pages 子路径后仍能保持同一份本地数据。

存储键：

```text
ai-infrastructure-books:reading-state:v1
```

数据结构：

```json
{
  "version": 1,
  "books": {
    "02-overseas-network": {
      "completed": [
        "01-after-vps",
        "02-login-server"
      ]
    }
  }
}
```

状态只保存在当前浏览器，不进行账户同步或跨设备同步。读取到未知版本、无效 JSON 或
不符合结构的数据时，前端会回退为空状态，不影响正文阅读。
