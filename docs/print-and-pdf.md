# 打印与 PDF

校订日期：2026-07-27

每本启用打印的书籍使用：

```text
/books/[book]/print/
```

页面根据书籍注册表的 print settings 和内容集合显式 `order` 合成。第一册与第二册
都包含封面、目录、开始之前、第 1—12 章、附录和资料来源。打印 CSS 使用 A4 纵向和
浅色高对比配色，隐藏站点页头、侧栏、复制按钮和交互控件；Windows/macOS 两套内容
都进入正文，教学仿真界面保留字段关系但移除屏幕阴影和深色背景。

浏览器中选择“打印或导出 PDF”，纸张使用 A4，缩放保持默认。浏览器分页实现可能略有
差异，但不得出现正文丢失、重叠或页面级横向溢出。

验收 PDF 存放在忽略版本控制的 `output/pdf/`。发布前至少记录页数、文件大小、空白页、
截断、溢出、深色背景和网页控件是否误入，并使用 Poppler 将页面渲染成图片抽查封面、
目录、正文、复杂表格/仿真界面和资料来源。
