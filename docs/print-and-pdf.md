# 打印与 PDF

校订日期：2026-07-26

整册打印入口：

```text
/books/02-overseas-network/print/
```

该页面由内容集合按显式 `order` 合成，包含封面、目录、开始之前、第 1—12 章、附录和
资料来源。打印 CSS 使用 A4 纵向和浅色高对比配色，隐藏站点页头、侧栏、复制按钮和
交互控件；Windows/macOS 两套内容都进入正文。

浏览器中选择“打印或导出 PDF”，纸张使用 A4，缩放保持默认。浏览器分页实现可能略有
差异，但不得出现正文丢失、重叠或页面级横向溢出。

验收 PDF 存放在忽略版本控制的 `output/pdf/`。发布前至少记录页数、文件大小、空白页、
截断、溢出、深色背景和网页控件是否误入，并使用 Poppler 将页面渲染成图片抽查封面、
目录、正文、复杂表格/仿真界面和资料来源。
