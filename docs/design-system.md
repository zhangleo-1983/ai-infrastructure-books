# 设计系统

校订日期：2026-07-26

## 视觉命题

像一本现代中文官方操作手册：浅灰纸面、白色阅读层、蓝色导航线索、深色终端，
重点依靠排版和信息层级，不依靠装饰性卡片。

## Token

所有全局 Token 位于 `src/styles/tokens.css`：

- 颜色：背景、表面、文字、边框、蓝色主色及成功、警告、危险状态。
- 字体：操作系统中文无衬线字体栈和系统等宽字体栈。
- 字号：从辅助文字到书籍封面的响应式字号。
- 间距：以 4px 为基础的有限间距级别。
- 圆角：从 8px 到 28px，仿真窗口和书籍封面可以使用较大圆角。
- 阴影：只保留一个克制的浮层阴影。
- 宽度：正文 46rem、整体内容 74rem、宽屏 90rem、侧栏 17rem。
- 断点：570px、768px、1024px、1440px。

CSS 自定义属性不能直接用于原生媒体查询，因此断点数值在 Token 文件注释中集中声明，
实际 `@media` 查询必须与该处同步。

## 长文排版

- 正文默认行高为 1.78。
- 文章正文宽度控制在约 46rem。
- 不引入外部字体文件。
- 手机端正文左右留白不低于 16px。
- 表格、代码和流程图只能在自身容器内滚动，不能造成页面横向溢出。

## 深色和打印

主题支持 `system`、`light`、`dark`。首次访问跟随系统；用户选择通过带版本号的
localStorage 键保存。首屏内联脚本在样式绘制前恢复状态，减少主题闪烁。

打印时强制使用高对比浅色配色，隐藏站点导航、复制按钮和交互控件。整册打印页包含
封面、目录、15 个内容单元与章节分页；终端改为浅色，表格和仿真界面限制在 A4 内容
宽度内。

## 无障碍状态

- 全站提供跳到正文链接与可见焦点。
- 交互控件最小高度为 44px。
- 完成状态同时使用文字、勾选符号和 `aria-label`，不只依靠颜色。
- 搜索和复制反馈使用 `aria-live`。
- `prefers-reduced-motion` 下关闭平滑滚动并压缩过渡时长。
- 仿真窗口使用带名称的 `figure`，装饰性圆点与图标对辅助技术隐藏。
