# 静态搜索

校订日期：2026-07-27

搜索使用 Pagefind，在 `npm run build` 的第二步从 `dist/` 生成静态索引。开发服务器不会
生成索引；验证搜索必须使用：

```bash
npm run build
npm run preview
```

只有章节页中带 `data-pagefind-body` 的正文进入索引。整册打印页、404、封面目录、站点
导航与完成控件被排除，避免重复内容。结果显示书名、章节/小节标题和匹配摘要，并可用
方向键与 Enter 打开。摘要只保留 Pagefind 的文字和 `mark` 高亮，不直接注入返回的
HTML。

每本书是否进入搜索、哪些 `chapterType` 可以索引，由 `src/data/books.ts` 中的
search settings 决定。结果中的所属书籍名称同样来自注册表。

Pagefind 的 `zh-cn` 模式不支持 stemming。第一册与第二册各维护 16 个固定样本，
分别覆盖购买、支付、VPS、SSH 以及 3X-UI、VLESS、客户端和故障排查。测试只要求
首批结果包含预期章节，并确认整册打印页不会重复进入结果；不为中文 stemming 引入
后端搜索服务。对已经由样本确认的分词边界，只在前端维护极小的等义词映射，例如把
“实名认证”按“额外审核”检索、把“端口”按界面常用字段 `Port` 检索；输入框和结果
跳转仍使用读者原始关键词语境。
