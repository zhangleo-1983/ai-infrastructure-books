# 守住并维护服务器：安全、备份与故障处理：规划与样章记录

状态：整册 draft；目标是先完成 3 篇样章，再扩展为 15 个内容单元。

## 读者结果
面向已经运行服务的用户，建立最小权限、更新、备份、监控和故障响应的长期习惯。

## 学习主线
最小权限、更新、备份、监控、故障响应

## 章节规划

1. `01-operations-boundary`：**运维负责什么**。定义服务、数据、凭证和责任边界。
2. `02-inventory-and-risk`：**建立资产清单与风险表**。知道服务器上有什么、谁能访问和何时停止。
3. `03-accounts-and-ssh`：**收紧账户与 SSH**。使用密钥、sudo 和登录审计降低暴露面。
4. `04-firewall-and-exposure`：**管理端口与公网暴露**。只开放必要入口并验证实际监听。
5. `05-updates-and-releases`：**安全更新与版本发布**。区分系统更新、镜像更新和应用迁移。
6. `06-logs-and-observability`：**读日志与健康指标**。从时间、服务和请求 ID 定位问题。
7. `07-backup-design`：**设计可恢复的备份**。同时考虑频率、保留期、加密和异地副本。
8. `08-restore-drill`：**做一次恢复演练**。验证备份真的能还原，而不是只看文件存在。
9. `09-alerts-and-costs`：**告警、费用与容量**。设置可行动的阈值，避免噪声和意外账单。
10. `10-incident-response`：**故障发生时先做什么**。按止损、取证、恢复、复盘的顺序行动。
11. `11-security-review`：**进行一次安全复核**。检查凭证、依赖、权限和公开入口。
12. `12-retirement-and-handoff`：**退役与交接**。安全撤销入口、归档证据并确认不再计费。
