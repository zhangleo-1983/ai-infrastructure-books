## 不阻塞当前 RC 的边界

以下项目用于提高下一版对厂商实时状态的置信度，不代表当前已经发现故障：

- 中国大陆不同地区、运营商和时段的普通浏览器访问差异；
- 测试账户实际出现的支付方式、额外审核和 KYC 分支；
- 东京、洛杉矶的实时库存、价格和 Looking Glass 表现；
- Vultr 当前创建页面的字段名称、默认值和排列变化；
- 真实实例中的密码、SSH 密钥、防火墙、账单和销毁闭环。

Vultr Status 曾对非浏览器自动链接请求返回 403。该结果只能说明自动请求可能受到
访问策略限制，不能推断中国大陆家庭宽带会返回 403，也不构成当前版本的发布阻塞。

如果真实测试或稳定读者反馈表明注册、官方支付、独立公网 IPv4、Ubuntu x64、
密码登录或 SSH 密钥登录中的任一主线无法完成，应立即把对应问题升级为阻塞问题。

## 安全与隐私边界

- 仓库中不得写入真实 IP、密码、SSH 私钥、支付记录、Cookie 或身份材料；
- 内部实测截图不得直接用于公开图书；
- 不使用共享账户、代付、推广返利、破解软件或非官方充值渠道；
- 价格、库存、支付和审核结果以读者本人账户当前页面及官方支持回复为准。

## 进入正式版的建议条件

`v1.0.0` 前建议至少完成一次合法测试账户闭环：

1. 创建一台具有独立公网 IPv4 的 Ubuntu 24.04 LTS x64 实例；
2. 在 Windows 和 macOS 验证密码与 ED25519 密钥登录；
3. 核对防火墙、小时价格、持续计费和 Billing History；
4. 销毁实例并检查备份、快照、Reserved IP 等独立资源；
5. 将脱敏结论回填到 `fact-check.md`；
6. 再次运行 `npm run check:all`、`npm audit` 和 `git diff --check`。

这些实测不是当前教学仿真版 RC 的公开阅读前置条件。
