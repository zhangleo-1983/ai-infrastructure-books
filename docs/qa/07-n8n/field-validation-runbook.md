# 第七册独立实机校订方案

编制日期：2026-09-11。Owner 已验收第七册 15 个 draft，并授权从第七册开始进入实机校订。本方案先建立可停止、可恢复、可清理的单一教学环境；书籍继续保持 `drafting / 0.0.0`。

## 1. 范围与证据规则

目标是在一台全新专用环境中验证 n8n 的安装、工作流、凭证、Webhook、执行记录、备份与退役路径。贯穿案例只使用合成报名资料，不发送真实邮件、不写入真实 CRM、不接入真实客户数据。

所有步骤记录时间、版本、预期、实际、证据代号、费用和恢复状态。真实域名、IP、邮箱、密码、token、Cookie、Webhook URL、凭证内容和备份原文只保存在受控记录中，仓库与聊天只保留代号和脱敏结论。

单门通过并恢复基线后才进入下一门。发现对象归属、费用或共享依赖不清，立即停在只读核对；不通过扩大端口、关闭签名校验、放宽访问控制或重复请求掩盖失败。

## 2. 对象与费用卡

| 代号 | 用途 | 执行前必须核对 |
| --- | --- | --- |
| VPS-A | 专用 Ubuntu 24.04 LTS amd64 | 提供方、地域、套餐、计费粒度、流量、预算、最迟销毁时间 |
| ZONE-A | 无业务冲突的教学主机名 | 所有权、DNS/ DNSSEC 基线、既有记录、续费责任 |
| TUNNEL-A | 唯一教学 Tunnel 与 connector | 组织、现有 route、安装来源、凭证保管、无其他业务依赖 |
| N8N-A | 本次唯一 Compose 项目 | 固定 n8n 版本、镜像摘要、回环端口、数据卷 |
| CRED-A | 仅用于占位验证的可撤销凭证 | 提供方、权限、撤销方式；默认不创建真实第三方凭证 |
| BACKUP-A | VPS 外受控备份 | 保存位置、加密、访问者、保留期限、删除范围 |

执行前填入本轮累计费用上限和最迟清理时间。停止容器或停止实例不自动等于停止账单；不自动充值、升级套餐或开通付费功能。

## 3. G1—G8 闸门

### G1：只读盘点与专用环境

核对账户、报价、域名和 Tunnel 基线；按获准规格创建唯一 VPS，安装官方 Docker/Compose，限制 SSH 和入站端口；如使用 Tunnel，只建立无 route connector。通过条件是对象归属、预算、主机指纹、版本和公网隔离均有证据。

### G2：固定版本的回环部署

从 n8n 官方文档选择固定版本，在全新目录生成唯一加密密钥，Compose 只发布 `127.0.0.1`。核对容器健康、数据卷、日志和磁盘余量；初始化页面只经 SSH 转发访问。失败时保留日志，不删除卷重装。

### G3：本人账户与基础设置

仅创建本人首位管理员，关闭公开注册，设置时区、执行记录保留期和诊断边界。退出重登并重建容器，确认账户、工作流和加密密钥持久。未确认唯一管理员前不接第三方凭证。

### G4：低风险工作流与凭证边界

建立“手动触发 → Set/Edit Fields → IF → 输出”的本地流程，输入为合成报名文字。凭证章节只验证占位配置和权限说明，不把真实 key 粘贴进流程。记录执行轨迹、输入输出和错误，不运行 Code/Execute Command。

### G5：受保护 HTTPS 与唯一 Webhook

先确认 Access 或等价身份保护，再建立唯一教学主机名和一个签名/密钥校验的 Webhook。桌面与手机只验证本人访问、刷新、一次合成请求和拒绝无会话请求；不公开管理端、不开放匿名 API。

### G6：一次一个故障并恢复

依次注入错误端口、停止 n8n、错误凭证、无效签名和重复 Webhook。每次只改变一个对象，记录实际状态码、日志层级和恢复动作；不制造高并发、不重放真实业务请求。

### G7：停写备份与隔离恢复

停止 Webhook 写入和工作流执行，正常停栈后归档 Compose、`.env`（受控）、数据卷和镜像摘要，生成 SHA-256 并保存 VPS 外副本。在独立目录、独立项目名和新卷中恢复，只验证工作流、执行记录和设置，不连接模型或第三方业务。

### G8：精确清理与费用收口

删除本轮 route、DNS、Access 应用、connector、容器、卷、备份、专用凭证和 VPS；复核公开 DNS、端口、账户资源和账单。保留根 zone、既有业务记录和与本轮无关的共享资源。清理后再做线上零答案/零实例/零附加资源证据。

## 4. 停止条件

费用无法界定、发现共享资源、出现真实业务数据、凭证权限超出最小范围、源站公网暴露、备份无法取回、恢复指向原卷，或连续失败可能扩大影响时，立即停止并记录为未覆盖；先恢复安全基线，再决定是否继续。
