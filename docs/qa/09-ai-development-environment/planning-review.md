# 建立自己的 AI 开发环境：终端、编辑器与项目协作：规划与样章记录

状态：整册 draft；目标是先完成 3 篇样章，再扩展为 15 个内容单元。

## 读者结果
从文件系统、终端和 Git 开始，建立适合 AI 工具协作的本地开发环境与恢复习惯。

## 学习主线
终端、Git、编辑器、环境变量、AI 协作

## 章节规划

1. `01-what-environment-means`：**开发环境到底包含什么**。分清操作系统、工具、项目和凭证。
2. `02-files-and-terminal`：**认识文件与终端**。用安全命令浏览、创建和撤销文件。
3. `03-install-tools`：**安装工具并记录版本**。建立可复现的工具清单和版本记录。
4. `04-git-basics`：**用 Git 保存每次变化**。理解仓库、提交、分支和恢复点。
5. `05-editor-workspace`：**整理编辑器工作区**。设置项目根目录、格式化和搜索边界。
6. `06-node-python-containers`：**准备运行时与容器**。理解 Node、Python、Docker 各自的职责。
7. `07-env-secrets`：**管理环境变量与密钥**。避免把 key、密码和本地配置提交进仓库。
8. `08-ai-coding-loop`：**建立 AI 编程协作回路**。把目标、上下文、补丁和验证分成步骤。
9. `09-review-diff-tests`：**审查 diff 与测试**。用最小检查确认 AI 修改没有越界。
10. `10-branch-and-rollback`：**分支、回滚与恢复**。在实验和稳定版本之间切换。
11. `11-local-web-debug`：**调试本地 Web 服务**。处理端口、日志、代理和浏览器缓存。
12. `12-maintenance-handoff`：**升级、备份与交接**。形成机器可读、人员可读的交接卡。
