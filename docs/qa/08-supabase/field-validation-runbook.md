# 第八册独立实机校订方案

编制日期：2026-09-12。目标是在 Supabase Free 组织中使用一套独立练习项目，验证数据库、RLS、Auth、Storage、函数/Webhook、备份恢复和退役路径。仅使用合成报名资料，不接入真实业务。

## G1—G8 闸门

1. **G1 只读盘点与专用项目**：核对组织、套餐、已有项目、区域、费用和删除边界；创建独立练习项目前确认不会触及既有项目。
2. **G2 项目与连接边界**：确认项目状态、区域、API URL、anon key 与 service role key 的使用边界；不把 service role key 放入浏览器或仓库。
3. **G3 第一张表与关系**：建立合成报名表、主键、外键和最小查询，记录成功与失败状态。
4. **G4 RLS 与认证**：为表启用 RLS，建立最小策略，验证未登录和已登录请求的差异。
5. **G5 Storage 与函数/Webhook**：建立练习桶和受保护函数；只发送合成请求并验证签名/身份边界。
6. **G6 故障与恢复**：一次只改变一个策略、字段、凭证或函数设置，记录错误并恢复基线。
7. **G7 备份、迁移与隔离恢复**：导出 schema/练习数据，在独立项目或本地隔离环境恢复并校验。
8. **G8 退役与费用收口**：停止入口，撤销临时 key，删除练习项目及附加资源，复核公开 URL、项目列表和账单。

任何暂停、删除既有项目、升级套餐、接入真实数据或创建付费资源都必须先停止并重新确认范围。
