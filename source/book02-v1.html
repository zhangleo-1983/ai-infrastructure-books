为什么不用手写 Xray JSON？

手写配置更灵活，但新手更容易因为逗号、括号、字段拼写和密钥对应关系失败。3X-UI 把高频操作转成表单，并提供分享链接、二维码、流量统计和订阅。

它适合个人管理，不等于企业级安全平台官方项目明确提示以个人用途为主，不建议将其直接视为生产环境网关。面板仍需强密码、随机路径、更新和备份。

“出站”需要配置吗？

本书的单节点入门方案通常不需要。Xray 默认的直连出站即可把通过验证的流量发往互联网。只有 WARP、链式代理、分流或特殊路由需求才需要新增出站。

页面打不开时

先核对地址

IP、端口、路径、斜杠都要完整；初装地址可能是 HTTP，不要擅自改成 HTTPS。

再检查防火墙

核心实操预计 15 分钟VLESS + Vision + Reality

先检查 443 端口是否空闲

Terminal
ss -lntp | grep ':443 '

没有任何输出通常表示 443 未被监听，可以使用；有输出则说明已有服务占用。新手可以改用 8443，或者先查清占用者。

为什么优先 443？443 是标准 HTTPS 端口，通常网络兼容性最好。但“使用 443”不是成功的必要条件，端口冲突时不要强行抢占。

Chapter 09

验证是否真正成功

“某个网页能打开”只能证明一部分。你还需要核对出口 IP、路由、DNS 与实际应用。

验证章节预计 7 分钟

四层验证法

1️⃣

客户端

内核运行、节点已选、无持续报错。

2️⃣

出口 IP

查询结果应与 VPS 公网 IP 或所在区域一致。

3️⃣

DNS

检查解析位置是否符合客户端配置预期。

4️⃣

应用

浏览器、AI 工具与实际软件分别测试。

出口 IP

连接前后分别访问 IP 查询网站，或在浏览器搜索 “what is my IP”。连接后结果应发生变化。也可访问：

浏览器地址
https://ipinfo.io

DNS 检查

浏览器地址
https://www.dnsleaktest.com

DNS 服务器位置不必与 VPS 城市完全相同，但不应在你明确要求代理 DNS 时仍持续暴露本地运营商解析。测试网站只能提供线索，不能证明“绝对匿名”。

延迟与速度

先看客户端延迟，再进行网页、视频和实际应用测试。速度受 VPS 区域、国际路由、晚高峰、套餐带宽和本地网络共同影响。

网站显示 403 不一定是节点坏了某些服务会根据出口 IP 的信誉、机房属性、账户地区或服务政策限制访问。更换协议通常不会改变 IP 信誉，必要时应更换 VPS 区域或公网 IP。

什么时候才需要回服务器？

面板或 Xray 升级、节点突然失效、修改端口或 UUID、备份、服务器重启后服务没有自动恢复，以及 IP 被目标服务限制时。

修改服务端后，记得更新订阅客户端不会凭空知道你换了 UUID、端口、Public Key 或 Short ID。服务端保存后，需要在客户端手动更新订阅。
Chapter 11

常见故障排查

不要同时修改十个选项。按照“服务器 → 面板 → 入站 → 订阅 → 客户端 → 网站”的顺序逐层定位。

SSH：Connection timed out

IP 错误、服务器未运行、本地网络不可达，或云防火墙阻挡。先在 Vultr 控制台确认实例为 Running，再核对 IP 与 22 端口规则。

SSH：Permission denied

用户名或密码错误。重新从实例页面复制；若使用 Limited User Login，可能不能直接使用 root。

SSH：REMOTE HOST IDENTIFICATION HAS CHANGED

常见于删除旧实例后 IP 被新实例复用。确认当前 IP 确实属于你的服务器，再执行 ssh-keygen -R 你的IP 删除旧指纹记录。

面板打不开

检查完整 URL、端口、随机路径和 HTTP/HTTPS；SSH 进入后运行 x-ui 查看面板状态；检查 UFW 与 Vultr Firewall 是否放行面板端口。

入站已保存，但节点 Timeout

确认入站启用、端口正在监听、云防火墙放行；客户端的 UUID、端口、Public Key、Short ID、Server Name、Flow 必须与服务端完全一致。

订阅显示 404

重新从对应客户端复制订阅地址，检查客户端是否被禁用或过期，并确认订阅服务相关设置。订阅失败不等同于 Xray 入站失败。

Clash 导入后显示 0 个节点

最常见原因是订阅格式不对。回到 3X-UI，选择 Clash/Mihomo 输出格式，再新建或更新订阅。

System Proxy 已开，但某个软件不走节点

该软件可能忽略系统代理。先确认软件自己的代理设置；确有全局接管需求时再开启 TUN。

开启 TUN 后公司内网、NAS 或打印机不可用

关闭 TUN 验证；使用 Rule 模式并为局域网地址设置直连。不要同时叠加多个 VPN、代理或安全客户端。

iPhone 显示 VPN，但没有网络

切换到“配置”路由、更新订阅、选择节点；确认手机订阅格式；删除并重建 iOS VPN 配置仅作为后续排查步骤。

能连接，但很慢

比较不同时间、本地网络和服务器区域；看 CPU/内存与套餐带宽；更换更近或路由更好的机房通常比反复修改协议参数更有效。

ChatGPT、Claude 或其他网站返回 403

先确认其他网站正常。若只有特定服务拒绝，通常与出口 IP、机房属性、账户地区或服务条款有关，不是 Reality 字段必然配置错误。

排障原则每次只改一个变量，改完立即测试并记录。不要在 UUID、端口、Target、Flow、DNS 和 TUN 之间同时乱改，否则无法知道哪一步起作用。

安全、备份与长期维护

能用只是起点。服务器暴露在公网，随机扫描和登录尝试会持续发生。

维护章节长期使用必读

最低限度的安全清单

强密码与随机路径

面板账号、密码、端口和路径不要使用 admin、123456 等可猜值。

及时更新

只从官方项目更新 3X-UI 和 Xray，更新前先备份。

限制暴露端口

只开放 SSH、面板和节点实际需要的端口。

独立设备身份

设备丢失时立即禁用对应 UUID，并更新订阅。

修改 root 密码

Terminal
passwd

输入两次新密码。输入过程仍然不会显示字符。请使用密码管理器保存长且唯一的密码。

系统更新

Ubuntu
apt update && apt upgrade -y
不要在关键使用前临时大升级更新可能重启服务或改变依赖。先备份，选择有时间排障的窗口操作。

备份什么？

3X-UI 面板数据库或面板导出的备份
当前账号、端口、路径和证书信息
Vultr Snapshot 或服务器快照
客户端订阅地址与设备清单

优先使用面板当前版本提供的备份/恢复功能。手动复制数据库前，应先确认当前版本实际存储位置和数据库类型，避免拿错文件。

进一步加固：留到后续运维册

创建 sudo 普通用户、配置 ED25519 SSH Key、关闭密码登录与 root 远程登录、Fail2ban、面板域名与 TLS、IP 白名单、自动备份和监控，适合在节点稳定后逐步完成。

不要为了“安全”一次性改完所有东西每完成一项加固，都要先开一个新的终端窗口验证仍能登录，再关闭旧连接，避免把自己锁在服务器外。

核心术语

VPS
运行在云端数据中心的虚拟服务器，你拥有系统管理权限。
SSH
安全远程登录协议，用于从本地终端控制服务器。
3X-UI
管理 Xray-core 的开源网页面板。
Xray-core
处理入站、出站、协议、路由和流量的后台内核。
Inbound
服务器接收客户端连接的入口，包含协议、端口和身份配置。
VLESS
轻量、无状态的传输协议，使用 UUID 进行客户端验证。
Reality
Xray 生态中的传输安全方案，与公私钥、Server Name、Short ID 等参数配合。
Vision
本书组合中使用的 Flow：xtls-rprx-vision。
UUID
客户端身份标识。泄露后应立即更换或禁用。
订阅 URL
客户端获取一个或多个节点配置的地址，本身也是敏感凭证。
System Proxy
让遵循操作系统代理设置的软件使用 Clash。
TUN
通过虚拟网卡接管更多流量，覆盖广但更容易与局域网或其他 VPN 冲突。
