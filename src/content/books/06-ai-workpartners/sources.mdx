# 资料来源与校订说明

本册优先讲跨产品都适用的任务方法，避免把易变的按钮位置写成固定事实。Codex、Claude、WorkBuddy 的具体功能、套餐、隐私条款和权限名称，应在读者实际使用前以对应产品的官方说明为准。

校订日期：2026-09-12。

## Codex 与 ChatGPT

- [Codex 使用案例](https://developers.openai.com/codex/use-cases)：了解 Codex 处理代码库、审阅和协作任务的官方示例。
- [Codex 快速开始](https://learn.chatgpt.com/docs/quickstart)：核对当前入口、项目与任务的基本使用方式。
- [Codex 权限模式](https://learn.chatgpt.com/docs/permission-modes)：核对工具在不同权限设置下可以执行的动作。
- [Codex 产物查看器](https://learn.chatgpt.com/docs/artifacts-viewer)：了解如何查看文件和其他任务产物。

## Claude

- [Claude Projects 介绍](https://support.anthropic.com/en/articles/9517075-what-are-projects)：核对项目知识与项目说明的用途。
- [创建和管理 Claude Projects](https://support.anthropic.com/en/articles/9519177-how-can-i-create-and-manage-projects)：核对当前项目操作和上下文范围。
- [Claude Code CLI 参考](https://docs.anthropic.com/en/docs/claude-code/cli-usage)：核对 Claude Code 当前命令、输入和权限相关选项。

Claude Projects 中不同对话不会自动共享全部聊天内容。需要复用的背景应放入项目知识或项目说明，并在开始新对话时检查实际可见内容。

## 腾讯 WorkBuddy

- [腾讯 WorkBuddy 官网](https://www.workbuddy.ai/)：核对产品定位和当前可用能力。
- [腾讯 WorkBuddy 产品指南](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Product-Guide)：核对桌面端任务、文件处理、Skill、MCP 与连接器说明。
- [腾讯 WorkBuddy 开放平台](https://open.workbuddy.cn/)：核对开放能力和开发者资料。

互联网上存在名称相近的其他产品。本册所称 WorkBuddy 专指腾讯 WorkBuddy；下载安装前应核对域名、开发者和官方说明。

## 易变事实清单

| 内容 | 本册处理方式 | 阅读时如何复核 |
| --- | --- | --- |

## 校订边界

官方页面也会更新。本页链接用于说明 2026-09-13 校订时的产品定位和操作边界，不表示所有功能在每个地区、账户、套餐和客户端中都相同。若界面与正文不同，优先确认任务目标、资料范围、权限和验收标准，再按当前官方说明找到相应入口。

阅读本册不代表任何产品之间存在合作、背书或功能等同关系。使用 AI 时仍应遵守所在地法律、服务条款和组织安全制度。
