## 附录：四张可以直接复用的卡片

把下面内容复制到自己的文档中，或打印后填写。首次练习只需使用必要字段；遇到新问题，再补充检查项。

## 任务简报卡

```text
目标：
读者：
允许使用的资料：
不能使用的资料：
限制：
验收标准：
必须人工确认的动作：
停止条件：
```

成功状态：没有读过原对话的人也能说出要完成什么、不能做什么。失败判断：“帮我处理一下”“做得专业一点”等词仍然需要猜测。

## 资料包清单

```text
任务名称：

[ ] 已列出允许读取的文件
[ ] 已排除无关目录和历史版本
[ ] 已标记资料日期或版本
[ ] 已删除不必要的敏感内容
[ ] 已确认资料允许进入当前工具

资料缺口：
遇到资料缺口时的处理：标记未知 / 暂停并询问
```

成功状态：AI 能指出自己实际使用了哪些资料。失败判断：任务依赖聊天之外的背景，却没有提供或说明。

## 权限检查卡

```text
[ ] 只能阅读必要资料
[ ] 修改范围已写明
[ ] 运行命令前已说明影响与回滚
[ ] 对外发送、付款、删除和发布保留人工确认
[ ] 敏感凭证没有进入提示词或截图
```

成功状态：工具只能完成本轮明确允许的动作。失败判断：为了省一次确认，授予了整个磁盘、邮箱或云盘的长期访问。

## 结果审阅卡

```text
[ ] 目标对象与读者正确
[ ] 每个关键事实都能回到原始资料
[ ] 推断、未知项和待确认项已区分
[ ] 格式、文件名和保存位置正确
[ ] 无关文件没有变化
[ ] 没有未经确认的外部发送、发布、付款或删除
[ ] 发现错误时有恢复方法
```

成功状态：每一项都能用文件、差异、日志或回执证明。失败判断：只因为文字流畅或页面看起来正常就判定通过。

## 交付卡

```text
工具与版本：
使用的资料：
完成的动作：
已运行的检查：
仍待确认的问题：
撤回或恢复方法：
```

成功状态：接手者知道当前结果、证据和下一步。失败判断：交付卡只写“已完成”，没有说明检查范围和未解决问题。

## 一页任务记录

```text
日期：
任务名称：
使用的工具：
开始前风险：
实际读取的资料：
实际产生的修改或动作：
检查证据：
最终判断：通过 / 有条件通过 / 未通过
待确认问题：
下次模板需要改进的地方：
```

建议保留任务记录，但不要在里面复制密码、验证码、API Key、私钥或完整客户资料。
