## 获取并检查官方 Compose

在 VPS 的 SSH 终端创建专用目录，保存官方 Compose 和环境文件。不要把真实密钥写进聊天或 Git。执行配置检查时只看退出码和脱敏字段，不能把完整环境输出粘贴出来。

<CodeBlock label="在 VPS 的 SSH 终端：目录与配置检查示例" code={`mkdir -p ~/docker-labs/n8n
cd ~/docker-labs/n8n
chmod 700 .
test -f docker-compose.yml && echo "Compose 文件存在"
sudo docker compose config -q`} />

配置通过后再启动。主机端口只绑定到 `127.0.0.1`，然后从本地电脑用 SSH 转发访问。成功状态是容器健康、管理页面能打开、没有额外公网监听。失败判断是 Compose 解析失败、端口冲突、容器反复重启或主机监听了 `0.0.0.0`；先停止并查看日志，不要盲目重试。

<strong>成功状态：</strong>版本、监听地址和数据目录都能从部署卡与有效配置对应。<strong>失败判断：</strong>用来历不明的安装脚本替代官方文件，或为了“先打开看看”放开公网端口。
