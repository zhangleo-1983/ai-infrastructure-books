## 不要只看连线

连线表示可能的执行路径；真正运行时，前一个节点必须产生后一个节点需要的字段。一个节点可以输出多条记录，每条记录有自己的 JSON 字段。表达式（Expression）是在运行时读取字段的写法，字段名拼错会得到空值或 `undefined`。

## 逐节点验证

先执行触发器，确认它产生一条记录；再执行字段节点，打开 Input 和 Output 对照字段名；最后执行结果节点。每次只改一处，避免多个错误叠在同一条执行记录中。

<strong>成功状态：</strong>每个节点的输出都包含下一节点需要的字段。<strong>失败判断：</strong>节点绿色但输出没有目标字段，或直接复制旧表达式；暂停运行，打开该节点的 Input 面板重新选择字段。
