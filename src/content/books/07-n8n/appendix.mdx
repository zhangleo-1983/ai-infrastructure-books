## 快速查阅

| 看到什么 | 先查哪里 |
| --- | --- |
| 没有执行记录 | 触发器是否激活、入口是否收到请求 |
| 字段为 `undefined` | 上游输出、字段名和表达式 |
| 401 / 403 | 凭证状态、权限范围和过期时间 |
| 429 | 提供方限制、退避和是否重复写入 |
| Webhook 被重复触发 | 签名、时间戳、幂等键和重放日志 |
| 恢复后凭证不可用 | 加密密钥、版本和备份来源 |

## 风险节点

Code、Execute Command、文件系统和未经核验的社区节点可能扩大主机或数据权限。第一版练习不需要它们；若确有需求，应建立独立项目、最小权限和单独备份，并先阅读 n8n 官方安全说明。

| 练习对象 | 可以保留 | 不要直接带入 |
| --- | --- | --- |
| 工作流定义 | 节点、连线、字段说明 | 真实 URL、key、客户数据 |
