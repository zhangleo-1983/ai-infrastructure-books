<Callout type="info" title="所有者不是普通成员">
  第一个完成初始化的人通常拥有最高权限。只用本人邮箱和强密码，完成后关闭不需要的注册路径；不要为了测试创建第二个真实用户。
</Callout>

## 初始化顺序

1. 通过 SSH 本地转发打开管理界面，确认地址不是公开 IP。
2. 创建本人所有者账户，保存恢复方式，不把密码写入仓库。
3. 核对 `N8N_ENCRYPTION_KEY` 已持久化，重启后仍能读取设置。
4. 在用户与权限页面确认没有未知成员，再创建练习工作流。

如果重启后再次出现初始化页，先停止服务并检查数据目录、卷名和权限；不要重新注册第二个所有者。若忘记加密密钥，停止继续创建凭证，先从受控备份找回密钥并确认来源。

<strong>成功状态：</strong>唯一所有者可登录，重启后设置和用户仍在，未创建不必要的真实凭证。<strong>失败判断：</strong>未知用户存在、公开注册仍开着，或密钥只保存在当前容器；停在初始化阶段。
