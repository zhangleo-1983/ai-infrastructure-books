## 这次要做成什么

n8n 是把多个步骤连成工作流的自动化工具。工作流是按顺序运行的一组节点；触发器决定什么时候开始，节点处理数据，执行记录保存每次运行的输入、输出和错误。

贯穿案例叫“活动报名整理器”。它只使用作者合成的一行报名文字，例如“林林，周六下午，带一位朋友”。流程先把文字整理成字段，再判断人数是否超过练习上限，最后返回结构化摘要。它不会给真实联系人发邮件，也不会写入真实 CRM。

## 自动化、脚本和外部写入不是一回事

脚本通常由你在终端手动启动；自动化工具会保存流程、凭证和执行记录，按照触发条件再次运行。只要流程调用了 HTTP、邮件、表格或数据库节点，就可能改变外部系统。节点显示绿色只表示本次执行没有报告错误，不代表业务结果已经被人工确认。

| 名词 | 本册中的含义 | 第一次练习的边界 |
| --- | --- | --- |
| 触发器 | 让工作流开始运行的节点 | 先用手动触发，不接真实事件 |
| 凭证 | 供节点访问服务的加密配置 | 使用占位凭证或本地练习，不粘贴真 key |
| 执行记录 | 一次运行的输入、输出和错误 | 保留一条低敏感样本，随后清理 |
| Webhook | 可由 HTTP 请求触发的入口 | 后续单独讲签名、重放和公开范围 |

<strong>成功状态：</strong>你能说出案例读了什么、写了什么、怎样停止。<strong>失败判断：</strong>把工作流当成“只会在网页里画图”，或无法指出凭证和执行记录位置；此时停在准备阶段。
