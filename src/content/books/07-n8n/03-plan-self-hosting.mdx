## 部署卡至少写清六项

| 项目 | 记录内容 | 成功状态 |
| --- | --- | --- |
| 版本 | n8n 版本和镜像摘要 | 能从镜像或启动日志核对 |
| 主机 | Ubuntu、架构、CPU、内存、磁盘 | 余量足够且归属明确 |
| 入口 | 管理入口、回环端口、HTTPS 方案 | 未配置公开旁路 |
| 数据 | n8n 数据目录或命名卷 | 知道备份对象和权限 |
| 秘密 | `N8N_ENCRYPTION_KEY` 等 | 只由本人保管，权限 600 |
| 费用 | VPS、流量、第三方 API | 能停止或销毁每个对象 |

n8n 的凭证依赖加密密钥。丢失密钥可能导致备份里的凭证无法解密，因此备份不能只拷贝工作流 JSON。自动化调用第三方 API 还可能产生对方费用；n8n 执行成功不代表费用为零。

<strong>成功状态：</strong>部署卡中每一项都有负责人、核对方法和停止动作。<strong>失败判断：</strong>只有“装一个 Docker”而没有数据、密钥或费用记录；停在规划阶段。
