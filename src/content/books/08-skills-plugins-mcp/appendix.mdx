这些模板只记录权限与流程，不保存密码、API Key、令牌、验证码、私钥或完整授权 URL。

## 更新与撤销清单

```text
[ ] 保存当前版本、配置摘要和通过样例
[ ] 检查新增权限、数据去向和兼容性
[ ] 使用相同合成样例做更新后回归
[ ] 在客户端禁用或卸载
[ ] 断开客户端连接
[ ] 在外部服务撤销授权或令牌
[ ] 清理受控范围内的配置和临时资料
[ ] 复测旧查询已无法访问新数据
[ ] 更新个人扩展目录与复核日期
```

成功状态是每一步都有位置或证据。失败判断是只凭界面图标消失就宣布撤销完成。
