## 插件：一组被打包的能力

插件通常把一组相关能力装进 AI 产品，例如搜索资料、读取某项服务或提供专用工作流程。不同产品对“插件”的定义并不统一，应以实际包含的 Skill、工具、连接和权限为准。

## 把插件拆开看

```text
说明：告诉 AI 什么时候以及怎样使用。
工具：执行查询、读取或修改动作。
连接：让插件访问外部账户或服务。
资源：模板、示例、脚本或参考资料。
界面：安装、启用、更新和卸载入口。
```

插件显示为一个名称，不表示其中所有能力拥有相同风险。只读搜索与发送消息需要不同权限和确认方式。

## 安装前制作能力边界卡

| 项目 | 要记录什么 |
| --- | --- |
| 解决的任务 | 当前缺口以及预期结果 |
| 发布者 | 官方名称、主页和文档 |
| 包含能力 | Skill、工具、连接器或资源 |
| 数据范围 | 会读取和传出的字段 |
| 可执行动作 | 查询、创建、修改、发送或删除 |
| 生命周期 | 更新、禁用、卸载和撤销方法 |

找不到发布者、权限或卸载说明时，停在评估阶段。

## “已安装”和“已连接”不是一回事

安装插件可能只把能力加入产品；连接账户会进一步授予外部访问。安装完成后检查连接列表和实际权限，不要把授权页面当作例行下一步。

## 先选择无账户或只读试用

优先使用公开资料、合成文件或只读账户测试插件能否解决任务。确认输出和日志后，再决定是否连接真实服务。试用失败就卸载并检查是否留下连接或令牌。

## 本章验收

成功状态是插件被拆成可核对的能力、工具、连接和资源，每项权限都有用途。失败判断是把插件名称当作可信保证，或安装后直接连接整个工作账户。
