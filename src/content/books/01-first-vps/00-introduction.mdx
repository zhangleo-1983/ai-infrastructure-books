<section className="book-section" id="book01-start-result">
  ## 完成后，你手里应该有什么

  <ComparisonTable>

  | 交付物 | 成功状态 | 失败时先看哪里 |
  | --- | --- | --- |
  | 正在运行的 VPS | 控制台明确显示 Running | 实例是否仍在创建、审核或停止状态 |
  | 独立公网 IPv4 | 实例详情页显示可复制的 IPv4 | 是否误选 IPv6-only、NAT 或私网地址 |
  | Ubuntu 系统 | Ubuntu 24.04 LTS、amd64 | 是否误选应用镜像、Windows 或其他架构 |
  | 管理员账户 | `root`，或能够使用 sudo 的用户 | 默认用户名和 Limited User 选择 |
  | 登录凭证 | 已安全保存密码，或知道私钥文件位置 | 不要把公钥和私钥混为一谈 |
  | 首次 SSH 登录 | `whoami` 返回预期管理员身份 | IP、22 端口、用户名和认证方式 |
  | 服务器地区 | 已记录东京或实际选择的备选地区 | 不要把账单地址当成服务器地区 |

  </ComparisonTable>

  <Callout type="info" title="独立公网 IPv4 是第一版的必需条件">
    第一版不使用 IPv6-only、NAT VPS 或共享 IPv4。第二册需要通过公网地址登录、配置和验证服务器，因此下单前与开通后都要核对 IPv4。
  </Callout>
</section>

<section className="book-section" id="book01-start-route">
  ## 本书采用哪条路线

  主线使用 Vultr Cloud Compute / Shared CPU，并采用下面的教学默认值：

  <ComparisonTable>

  | 项目 | 第一版默认值 | 为什么 |
  | --- | --- | --- |
  | 地区 | 日本东京 | 形成统一演示路径，不代表对每位中国用户都是最佳网络 |
  | 地区备选 | 美国洛杉矶 | 东京缺货或实测不合适时的备选 |
  | 配置下限 | 1 vCPU、1 GB RAM、25 GB 系统盘、至少 1 TB 月流量 | 足以支撑第一、二册的轻量学习路径，并留出基础余量 |
  | 系统 | Ubuntu 24.04 LTS | 与第二册已经验收的系统一致 |
  | 架构 | x86_64 / amd64 | 减少零基础读者遇到的安装分支 |
  | 公网地址 | 独立公网 IPv4 | 保持 SSH 和第二册配置路径清晰 |
  | 登录方式 | SSH 密钥优先，密码路径完整保留 | 兼顾安全建议和不同账户、镜像的实际选择 |

  </ComparisonTable>

  AWS Lightsail 和阿里云中国站 ECS 只在附录中提供选择映射与最低核对项，不会在正文中复制三套完整购买步骤。

  <Callout type="warning" title="东京只是演示地区，不是网络承诺">
    物理距离、网络路径、高峰拥塞、IP 信誉和第三方服务政策都会影响实际体验。不要因为书中选择东京，就推断东京在任何时间、任何地区或任何用途下都一定更快。
  </Callout>
</section>

<section className="book-section" id="book01-start-boundary">
  ## 这本书不做什么

  本书不会：

  - 安装 3X-UI、Xray、Docker 或业务软件；
  - 配置 VLESS、Reality、Clash Verge Rev 或 Shadowrocket；
  - 购买域名或配置 Cloudflare；
  - 提供服务商价格排行、长期有效优惠券或返利链接；
  - 指导绕过支付、实名、地区或平台安全限制；
  - 承诺某个 IP 可以访问特定第三方服务；
  - 承诺自建 VPS 能带来匿名性或不可追踪性。

  完成首次 SSH 登录后，你会进入第二册《拥有自己的海外网络》。第二册将从已经可登录的 Ubuntu VPS 继续，而不是让你再次购买服务器。
</section>
