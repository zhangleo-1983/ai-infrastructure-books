  ## 本页怎样使用

  第一册把容易变化的事实尽量链接到服务商、操作系统或平台的官方资料。官方页面仍可能更新，因此“链接存在”不等于书中所有按钮名称永远有效。

  当前内容校订日期：**2026-07-27**。

  当前校订状态：

  - 已完成官方文档层面的技术路线复核；
  - 已完成“开始之前”、第 1—12 章、附录与本页的公开 Release Candidate；
  - 厂商页面全部使用 HTML 与 CSS 教学仿真，不是当前控制台的像素级截图；
  - 尚未使用中国大陆测试账户完成 Vultr 注册、支付宝、人工审核、东京库存和双认证登录的实机全流程复核；
  - AWS Lightsail 与阿里云 ECS 只作为附录中的最小补充选择；
  - 当前价格、库存、支付方式和验证要求仍以读者自己账户中的实时页面为准，不构成可用性承诺。

  <Callout type="info" title="仿真界面和“校订于”分别表示什么">
    仿真界面只表达字段关系、操作顺序和成功状态，不声称复刻厂商当前页面；“校订于”表示作者在该日期检查过官方说明，不代表服务商承诺以后不再改变。真正下单前仍需核对当前控制台、结算页、账单说明和服务条款。
  </Callout>

  ## 不阻塞公开阅读、但仍需继续复核的事项

  - 使用中国大陆网络与测试账户完整试走 Vultr 主线；
  - 核对注册、邮箱验证、两因素认证和恢复码；
  - 核对当前 Alipay、银行卡和 PayPal 分支；
  - 核对额外身份验证与人工审核的实际提示；
  - 核对 Tokyo 和 Los Angeles 当前库存、套餐字段与结算金额；
  - 分别创建密码实例和 ED25519 密钥实例；
  - 在 Windows 与 macOS 完成首次 SSH 登录和错误分支；
  - 核对实例状态、Overview、Firewall、Billing History 和销毁流程；
  - 在厂商界面或登录路径变化时，再校订第二册“开始之前”、首次登录、重新登录和故障排查内容；
  - 每个发布候选继续运行内容、安全、链接、响应式、打印、搜索与跨浏览器验收。

  详细执行记录维护在 `docs/qa/01-first-vps/fact-check.md`。该文件可能包含作者工作状态，不作为读者操作步骤。
