## 附录：四张检查卡

这些卡片可以用普通文档和表格填写。评估记录也受数据与凭证保护要求约束。

## 测试样例卡

```text
样例编号：
输入类别：
输入资料：
预期结果：
不可接受结果：
```

## 分层评分卡

```text
样例编号：
阻断项：通过 / 失败 / 无法判断
事实：0 / 1 / 2；证据：
完整：0 / 1 / 2；证据：
格式：0 / 1 / 2；证据：
可读：0 / 1 / 2；证据：
未知项：0 / 1 / 2；证据：
最终结论：通过 / 有条件通过 / 未通过
```

```text
耗时、调用、重试与费用：
人工评审：
相对基线的变化：
关键样例是否回归：
```

## 失败分析卡

```text
失败样例和首次偏差：
类别：资料 / 理解 / 事实 / 格式 / 工具 / 权限 / 评审
根因假设：
需要的证据：
本轮唯一修复：
最小复测：
完整回归：
```

## 发布、停止与回滚卡

```text
候选版本和主要变化：
测试与安全证据：
已知风险和无法判断：
批准人与范围：
漂移指标：
预警与停止条件：
上一版或降级方案：
回滚演练结果：
```

成功状态是所有判断都能追溯到运行与责任人。失败判断是只记录总分、最终截图或一句“看起来不错”。
