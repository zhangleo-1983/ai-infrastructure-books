  ## 本页怎样使用

  第四册的域名、DNS、Cloudflare Tunnel、HTTPS 和 Caddy 技术事实优先依据对应产品或治理机构的官方资料。控制台、套餐、支付、注册政策、安装命令和错误文案都会变化，因此“链接仍能打开”不表示未来界面与正文永远一致。

  当前事实与实机校订日期：**2026-08-23**。

  当前校订状态：

  - “开始之前”、第 1—12 章、附录和本页已经形成 15 个 Release Candidate 内容单元；
  - 全部内容使用 `draft: false`，已进入 production、Pagefind、完成状态和正式打印；
  - 主线固定为 Cloudflare Free 完整 DNS 设置、具名远程管理 Tunnel、官方 `cloudflared` APT 软件包和 `app.example.com → http://127.0.0.1:8080`；
  - Caddy 只作为附录对照，不与 Tunnel 主线同时配置；
  - 控制台界面均为 HTML/CSS 教学仿真，不是真实软件截图，也不声称与某个版本像素一致；
  - 已在不承载业务的隔离域名和临时 VPS 上完成 nameserver、DNSSEC、Tunnel、HTTPS、故障恢复与 Caddy 对照，G8 已永久删除教学 route、DNS、connector、Tunnel、VPS 和本机实验凭证；
  - 仓库没有保存真实域名、IP、nameserver、DS、账户、UUID、token、邮箱或私钥；
  - 本页不把第三方博客、一键脚本、镜像站、论坛回答或 AI 生成答案作为唯一技术依据；
  - 第四册已完成脱敏端到端实机校订；单次控制台排列、错误码和等待时间仍不扩展为所有账户与地区的固定结果。

  <Callout type="warning" title="一次实机通过也不能替代后续复核">

  <Callout type="info" title="TTL 不是全球倒计时">

<section className="book-section" id="book04-sources-https">
  ## HTTPS、证书、代理与应用安全

  <ol className="source-list">
    <li><a href="https://developers.cloudflare.com/ssl/" target="_blank" rel="noopener noreferrer">Cloudflare SSL/TLS</a>：浏览器到边缘、边缘到源站的连接与证书概念入口。</li>
    <li><a href="https://developers.cloudflare.com/ssl/edge-certificates/universal-ssl/enable-universal-ssl/" target="_blank" rel="noopener noreferrer">Enable Universal SSL</a>：full setup 激活后的默认签发、覆盖、代理要求与当前等待窗口。</li>
    <li><a href="https://developers.cloudflare.com/ssl/origin-configuration/ssl-modes/full-strict/" target="_blank" rel="noopener noreferrer">Full (strict)</a>：传统公网源站必须在 443 提供有效、匹配且受信的证书；失败可能返回 526。</li>
    <li><a href="https://developers.cloudflare.com/ssl/origin-configuration/origin-ca/troubleshooting/" target="_blank" rel="noopener noreferrer">Troubleshooting Cloudflare Origin CA</a>：Origin CA 只面向 Cloudflare 到源站，暂停代理或浏览器直连可能显示不受信。</li>
    <li><a href="https://developers.cloudflare.com/learning-paths/clientless-access/access-application/create-access-app/" target="_blank" rel="noopener noreferrer">Create an Access application</a>：自托管应用的身份策略边界；本册只解释，不配置。</li>
    <li><a href="https://developers.cloudflare.com/cache/concepts/default-cache-behavior/" target="_blank" rel="noopener noreferrer">Default cache behavior</a>：当前默认缓存类型和 HTML / JSON 边界，自定义规则会改变结果。</li>
  </ol>

  HTTPS 只说明传输加密和主机名身份的一部分，不自动提供应用登录、授权、数据备份、合规或匿名。Cloudflare Access、应用鉴权、缓存和 WAF 是独立能力。
</section>
