# 开始之前：Prompt 不是咒语

Prompt 可以理解为“给 AI 的任务说明”。它不是一句越神秘越有效的咒语，而是一份让双方减少误解的工作单。上下文是完成任务所需的背景和资料，验收标准则说明什么结果算合格。

同一句 Prompt 在不同模型、不同时间或不同资料下可能得到不同结果。稳定来自任务结构和检查过程，不来自某个“万能句式”。本册会练习把目标、读者、资料、限制、步骤和输出格式写清楚，再观察结果是否符合标准。

## 一次 AI 任务有六个部分

| 部分 | 它回答的问题 |
| --- | --- |
| 目标 | 最终要得到什么？ |
| 读者 | 谁会使用结果，在什么场景使用？ |
| 上下文 | AI 必须知道哪些背景和事实？ |
| 约束 | 什么必须保留，什么不能做？ |
| 输出 | 结果用什么结构呈现？ |
| 验收 | 怎样判断结果可以采用？ |

这六项不一定都写成长段落。一个五分钟的小任务可能只需六行；跨天任务则需要单独的资料包和交接摘要。

## 本册贯穿练习

你将把一份虚构的活动说明整理成“给第一次参加活动的人看的准备清单”。练习资料不要包含真实姓名、联系方式、账号、付款信息或内部文件。

先建立一个普通文本文件，写入以下内容：

```text
活动：社区旧书交换日
时间：周六 14:00—17:00
地点：社区活动室
参加者最多携带 10 本书，书籍需要清洁完整。
现场不接受现金交易，只进行交换或免费赠送。
儿童需要监护人陪同。
雨天活动照常。
```

这份资料刻意保持简单，方便你判断 AI 有没有增加原文不存在的规定。

## 开始前输入卡

```text
我要得到的结果：
结果给谁使用：
AI 可以使用的资料：
AI 不能补充或执行的内容：
我会怎样检查：
```

填写后先不要追求措辞漂亮。只要另一个人能够据此开始任务，输入卡就已经发挥作用。

## 本册完成标准

完成第 1—12 章后，你应能为一个真实的小任务写出输入卡，要求 AI 先计划再执行，用样例和检查表验收，并在结果不稳时定位是目标、资料、约束还是流程出了问题。

遇到敏感资料、不可逆操作或你无法判断真伪的结果时，先暂停并增加人工复核。

成功状态是练习资料、目标、限制和检查方法都已准备好。失败判断是把真实敏感资料作为练习，或仍希望只靠一句 Prompt 自动得到无需检查的最终结果。
