  ### 出口 IP

  连接前后分别访问 IP 查询网站，或在浏览器搜索 “what is my IP”。连接后结果应发生变化。也可访问：

  <CodeBlock label="浏览器地址" code="https://ipinfo.io" />

  ### DNS 检查

  <CodeBlock label="浏览器地址" code="https://www.dnsleaktest.com" />

  DNS 服务器位置不必与 VPS 城市完全相同，但不应在你明确要求代理 DNS 时仍持续暴露本地运营商解析。测试网站只能提供线索，不能证明“绝对匿名”。

  ### 延迟与速度

  先看客户端延迟，再进行网页、视频和实际应用测试。速度受 VPS 区域、国际路由、晚高峰、套餐带宽和本地网络共同影响。

  <Callout type="warning" title="网站显示 403 不一定是节点坏了">
    某些服务会根据出口 IP 的信誉、机房属性、账户地区或服务政策限制访问。更换协议通常不会改变 IP 信誉，必要时应更换 VPS 区域或公网 IP。
  </Callout>
