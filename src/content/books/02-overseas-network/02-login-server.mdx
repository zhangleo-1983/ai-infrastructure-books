    ### 路径 A：使用 SSH 私钥

    私钥是保存在自己电脑上的秘密文件。不要选择以 `.pub` 结尾的公钥，也不要把私钥上传到服务商控制台、聊天或网页表单。

    <PlatformTabs id="ssh-key-platform" firstPlatform="windows">
      <div slot="windows">
        默认 ED25519 私钥通常位于 Windows 用户目录下的 `.ssh` 文件夹。PowerShell 示例：

        <CodeBlock
          label="Windows · 把示例 IP 换成真实 IP"
          code={'ssh -i "$env:USERPROFILE\\.ssh\\id_ed25519" root@203.0.113.10'}
        />

        如果私钥名称或管理员用户名不同，同时替换文件名和 `root`。
      </div>
      <div slot="mac">
        默认 ED25519 私钥通常位于 `~/.ssh/id_ed25519`。终端示例：

        <CodeBlock
          label="macOS · 把示例 IP 换成真实 IP"
          code="ssh -i ~/.ssh/id_ed25519 root@203.0.113.10"
        />

        如果私钥名称或管理员用户名不同，同时替换文件名和 `root`。
      </div>
    </PlatformTabs>

    成功后可能只要求输入私钥保护密码，不会要求服务器密码。这个保护密码由你创建密钥时设置，不是 Vultr 账户密码。

  <div data-parity-ignore>
    ### 登录失败时先读错误文字

    <TroubleshootingItem title="Connection timed out / Connection refused">
      先检查实例是否 Running、IP 是否正确、Vultr Firewall 是否允许 TCP 22，以及防火墙来源是否仍包含你当前公网 IP。这类错误发生在认证之前，反复输入密码或换私钥不会解决网络问题。
    </TroubleshootingItem>

    <TroubleshootingItem title="Permission denied / Permission denied (publickey)">
      密码路径检查实际用户名、服务器密码和实例 IP；密钥路径检查私钥文件、对应公钥和实际用户名。不要使用 Vultr 网站账户密码，也不要把 `.pub` 公钥当作私钥。
    </TroubleshootingItem>

    <TroubleshootingItem title="Identity file ... not accessible">
      这是本地私钥路径或文件名错误。先在自己的电脑上确认文件位置，不要修改服务器、防火墙或重装实例。
    </TroubleshootingItem>
  </div>
