<section className="book-section" id="ch2-login">
  ## 第一次登录

  <PlatformTabs id="ssh-platform">
    <div slot="mac">
      <InstructionStep number={1} title="打开“终端”">
        按 <kbd>Command</kbd> + <kbd>空格</kbd>，搜索“终端”或 Terminal。
      </InstructionStep>
    </div>
    <div slot="windows">
      <InstructionStep number={1} title="打开 PowerShell 或 Windows Terminal">
        在开始菜单中搜索即可。现代 Windows 通常自带 OpenSSH 客户端。
      </InstructionStep>
    </div>
  </PlatformTabs>

  <CodeBlock
    label="把示例 IP 换成你的真实 IP"
    code="ssh root@203.0.113.10"
  />

  <TerminalMock title="第一次连接">
    <span className="term-green">user@computer</span>{" "}
    <span className="term-white">~ %</span>{" "}
    <span className="term-blue">ssh root@203.0.113.10</span><br />
    {"The authenticity of host '203.0.113.10' can't be established."}<br />
    {"Are you sure you want to continue connecting (yes/no/[fingerprint])?"}
  </TerminalMock>

  核对 IP 后输入：

  <CodeBlock code="yes" />

  <Callout type="warning" title="输入密码时不会显示星号">
    复制密码、粘贴、直接按回车。屏幕没有变化并不代表没有输入。
  </Callout>

  <TerminalMock title="登录成功">
    {"Welcome to Ubuntu 24.04 LTS"}<br /><br />
    <span className="term-green">root@vultr</span><span className="term-white">{":~#"}</span>{" "}
    <span className="term-blue">whoami</span><br />
    {"root"}<br />
    <span className="term-green">root@vultr</span><span className="term-white">{":~#"}</span>{" ▌"}
  </TerminalMock>

  看到 `root@……:~#` 即表示成功。退出时输入：

  <CodeBlock code="exit" />

  <ChapterChecklist chapterId="book02-chapter-02">
    我已经成功登录、执行 whoami，并使用 exit 退出。
  </ChapterChecklist>
