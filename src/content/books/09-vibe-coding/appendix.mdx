# 附录：四张检查卡

将这些模板复制到原型目录。模板不保存真实密码、API Key、令牌或用户资料。

## 原型需求卡

```text
用户：
主要动作：
输入：
输出：
不做什么：
完成标准：
```

## 用户路径与状态卡

```text
主要路径：
空状态：
输入状态：
加载状态：
结果状态：
错误状态：
每个状态的恢复动作：
```

## 浏览器验收卡

```text
[ ] 正确地址和标题
[ ] 主要路径逐步通过
[ ] 空、无效、很长和特殊字符输入有结果
[ ] 控制台无未解释错误
[ ] 没有计划外网络请求
[ ] 390px 窄屏无横向溢出
[ ] 只用键盘可以完成主要路径
[ ] 200% 缩放内容不丢失
[ ] 错误有文字说明
```

## 错误与最小修复卡



## 原型交接卡

```text
当前版本与位置：
安装、启动和访问方法：
主要路径：
数据来源与清理：
依赖和网络请求：
通过的检查：
已知问题与排除项：
恢复方法：
下一轮只做：
```

成功状态是接手者不依赖聊天记录也能运行、检查和恢复。失败判断是模板只写“已完成”，没有证据和边界。
