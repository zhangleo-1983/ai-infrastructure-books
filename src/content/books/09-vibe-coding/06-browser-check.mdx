# 浏览器检查：页面真的能用吗

不要只看代码或截图。打开页面，按用户顺序输入、点击、刷新和返回；再用手机宽度检查文字、按钮和错误提示是否仍可读。

## 先确认打开的是正确页面

记录本地地址和页面标题，刷新一次，确认不是旧缓存或其他服务。打开浏览器控制台，查看是否有红色错误；有错误先记录，不要只关闭提示。

## 按脚本完成主要路径

```text
1. 首次打开，看到标题、说明和空输入。
2. 输入“番茄、鸡蛋、面条”。
3. 点击“生成建议”。
4. 看到恰好三张建议卡。
5. 点击“重新输入”，输入框可再次编辑。
6. 刷新页面，回到记录中约定的初始状态。
```

每一步记录通过、未通过或无法判断，并附实际看到的文字。截图可以帮助说明问题，但不能替代点击和状态验证。

## 检查失败路径

清空输入后点击按钮，页面应显示明确提示且不生成假结果。输入超长文字、重复逗号和特殊字符，页面应保持可操作，不出现空白或无限加载。

## 查看控制台和网络

即使页面看起来正常，也检查控制台错误和意外网络请求。本册原型约定不联网；如果出现未知请求，应停止并追踪来源。

## 本章验收

成功状态是主要路径和失败路径都有逐步证据，控制台无未解释错误，失败后可以恢复。失败判断是只看截图，或桌面看起来漂亮但按钮无响应、网络请求与简报不一致。
