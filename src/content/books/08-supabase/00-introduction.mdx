## 为什么先做边界检查

本册使用合成资料和练习项目。先写下会读取什么、会写入什么、谁可以访问，以及出现费用或异常时怎样停止。密码、API key、订阅 URL 和私钥都不粘贴到正文、截图或 Git 仓库。

## 成功状态

你能用一句话说明本册的练习结果，并指出删除入口、撤销凭证和停止资源的位置。失败时不要继续扩大范围，先回到边界表逐项核对。
